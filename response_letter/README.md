# Response-letter directory

- `response_letter.tex`: current response source.
- `Reviewer_comments.txt`, `Reviewer_comments_toCN.txt`: received comments and translation.
- `paper_revision_policy.md`: revision decisions, not a replacement for source files.
- `figures/`: current figures and small numerical source tables used by the response.
- `literature/`: source papers and download/checksum index; PDFs stay outside Git.
- `review_notes/`: advisor annotation, kept locally and separately backed up.
- `submission_support/`: submission-form screenshots, not manuscript inputs.

Compile from this directory so `../latexCodes/figures/` references resolve.
Do not overwrite the submitted PDF under `../latexCodes/revision1/`.
See [the paper-file index](../docs/PAPER_FILES.md).
