# R2C1：方向性干扰与显式 RB 重叠验证

2026-09-19：21/21 组实验完成，六项基础测试通过，9 组旧设置均逐数组精确复现。结论是：**不能把正文干扰近似的偏差称为可忽略；在所测试的闭环负载下，显式方向性干扰反而得到更低的功率和违反概率，但尚未据此重评所有基线的排名。**

## 实验目的与边界

本实验分别检查两项近似，而不预设误差可忽略：

1. 用完整 DFT 码本上的平均有效增益，代替实际调度波束产生的干扰增益。
2. 用 RB 重叠的条件期望，代替实际频率索引重叠，并将平均干扰直接代入服务率公式。

仅新增独立验证程序，没有修改既有仿真源文件、模型权重、论文、回复信或 Fig.5–Fig.8 数据。新程序通过进程内适配器读取实际调度决定和私有物理信道；这些信息不会额外提供给决策算法。

代码版本：`4178976`。回退标签：`pre-r2c1-interference-validation-20260919`，指向实验前的 `ea6cdbb`。实验协议、样本、队列和摘要均另存于 `experiment/results/interference_validation_20260919/`。

## 配对方法

沿用当前正式实验的 Sionna RT 信道矩阵、原有逐时隙衰落、两阶段递推模型预测缓存、车辆轨迹、Poisson 到达、2 轮且占用量封顶的 GAP-HO、10 ms HO 中断、PET-BF 导频开销及 OTR-RA。每次仿真持续 30 s，300 帧，统计时去掉前两帧。没有重新运行射线追踪，也不声称进行了波形级或数据包级仿真。

首先使用旧服务率计算驱动完整闭环。在每个时隙，固定相同关联、实际选择的波束对、每车 RB 数量和队列状态，离线计算六种干扰/服务率。每个旧设置复现实验必须逐数组匹配最近完成的全负载实验，否则不接受结果。

然后在 13、29 Mbps 分别使用 3 个配对 seed，运行三种完整闭环：旧计算、正文平均近似、显式方向性干扰。闭环对照只替换微层物理服务率，HO、BF、RA 的决策逻辑和输入来源不变。队列发生变化后，后续调度会自然随之改变；不是把旧队列直接换一个公式后当作新系统结果。

固定调度诊断覆盖 1、13、23、29、35 Mbps，其中 13、29 Mbps 各 3 个 seed，其余各 1 个 seed。总计划为 21 次仿真，准确任务集合见 `run_plan.json`。各 seed 共享同一地图、车辆轨迹集合及模型，仅改变到达、衰落和独立 RB 映射随机性。

## 实际方向性干扰的计算

对于受干扰车辆 $v$，接收端始终使用其**服务链路的接收波束**。对于另一基站 $j$ 在某 RB 上服务的车辆 $w$，发射端使用其**实际服务于 $w$ 的发射波束**。交叉增益为

$$
g_{j,w\to v}=\left|\boldsymbol w_{R,v}^{H}\boldsymbol H_{j,v}\boldsymbol w_{T,j,w}\right|^2.
$$

这里使用从干扰基站 $j$ 到受干扰车辆 $v$ 的信道，而不是 $j$ 到其自身服务车辆 $w$ 的信道，也不是 $v$ 与 $j$ 之间的最优波束对。收发 DFT 波束均归一化；不同数据流的干扰按功率相加。

给定每车 RB 数量，每个基站独立对其 66 个 RB 索引均匀置换，再按照已确定的数量分配给本基站车辆。基站内无频率重叠，基站间可重叠。该映射使用独立、帧级设定种子的随机数流，不改变策略或衰落随机数。

重叠量的 Monte Carlo 检查验证的是这一**明确指定的随机映射实现**与条件期望公式的一致性，并不证明任意实际网络调度器都会产生独立均匀的频率索引。

在相同波束下，条件期望的**每 RB**干扰为

$$
\bar I_v=\sum_{j\ne m(v)}\frac{p_j}{K_\mu}\sum_{w:m(w)=j}k_w g_{j,w\to v}.
$$

显式映射则逐 RB 找到干扰基站在该 RB 上实际服务的车辆；没有占用时不产生该项干扰。服务量按每 RB 的 $\log_2(1+\mathrm{SINR})$ 求和，并扣除原有导频开销，不用 $\log_2(1+\text{平均 SINR})$ 代替。

这里“RB 映射的影响”既包括占用/空闲重叠，也包括重叠 RB 上实际对应哪个用户的发射波束。即使所有 RB 均被占用，重叠数量没有误差，后者仍会造成各 RB 干扰不同。因此 `overlap_only_directional` 更精确的含义是**保持方向性增益矩阵不变，将条件期望 RB 映射改为显式映射**，不是只扰动一个重叠计数。

## 六种诊断口径

| 标识 | 干扰增益 | RB 处理 |
|---|---|---|
| `legacy` | 原代码的帧级矩阵元素最大幅度平方，含原 dB 数值处理 | 期望重叠 |
| `frame_average` | 帧级 Frobenius/码本平均增益 | 期望重叠 |
| `average_expected` | 时隙级 Frobenius/码本平均增益，对应正文公式 | 期望重叠 |
| `directional_expected` | 时隙级实际调度收发波束增益 | 期望重叠 |
| `average_explicit` | 时隙级 Frobenius/码本平均增益 | 显式索引、逐 RB 服务率求和 |
| `directional_explicit` | 时隙级实际调度收发波束增益 | 显式索引、逐 RB 服务率求和 |

内部一致性核查发现，现有干扰预测标签也采用矩阵元素最大幅度定义，见 `experiment/prepare_stateful_trajectories.py:40`。因此，旧代码与正文平均公式并非同一计算口径。本实验没有擅自修改或重训预测器；`frame_average` 用于区分增益汇总方式变化和帧/时隙变化的影响。该内部实现历史不直接作为审稿回复的正文。

## 指标解释

- 干扰和服务率误差仅统计实际获得 RB 的微基站用户，避免把无服务时隙当作零误差。宏层仍参与闭环功率、队列和违反概率统计。
- “平均干扰之比”先按该用户 RB 数加权累加，再相除；不能仅用它判断瞬时误差。
- “汇总 SINR 误差”先在该用户实际获得的 RB 上平均干扰，再计算 SINR。表中的分位数是用户—时隙汇总 SINR 的分位数，**不是单 RB SINR 的分位数**。
- “潜在服务量”是给定 RB、波束和导频开销能提供的服务量，未按队列余额截断；不等于实际业务吞吐量。原始摘要另外保留按队列余额截断后的离开量对比。
- 闭环 $U$ 和 P99 沿用原论文的队列长度时延代理指标，不作为实际数据包端到端时延。
- 固定调度下发射功率必然相同，不能据此声称功率不受影响。功率及 $U$ 的变化只由独立闭环仿真判断。
- 统计先按 seed 分别计算，再报告 seed 间均值、范围和标准差；不会把同一轨迹上的大量相关车辆—时隙样本当作独立重复实验。

## 验证与复现

六项基础测试涵盖完整 DFT 码本平均恒等式、手工计算的实际交叉波束增益、归一化、基站内正交分配、无外小区时零干扰、穷举及 Monte Carlo 条件期望重叠。每帧还用实际服务链路对角项核对原 PET-BF 所选增益，每时隙核对 RB 数与旧队列更新。

```bash
python -m unittest test_interference_validation -v
python -u experiment/interference_validation.py case --mode legacy --rate 13 --seed 1 --gpu 0
python -u experiment/interference_validation.py case --mode average_expected --rate 13 --seed 1 --gpu 0
python -u experiment/interference_validation.py case --mode directional_explicit --rate 13 --seed 1 --gpu 0
python experiment/summarize_interference_validation.py --check-raw
```

已有结果不会被重复 case 命令覆盖。协议校验要求算法源代码及预测缓存保持不变；若后续修改这些文件，应建立新的输出协议和目录，而不是覆盖本实验。

详细数值及任务完成数见 [自动汇总表](results/interference_validation_20260919/aggregate/results.md)，机器可读统计见 `aggregate/summary.json`，逐用户—时隙诊断见 `samples/`，完整系统队列等结果见 `raw/`。摘要基于 FP64 计算，诊断样本压缩保存为 FP32，系统原始队列仍保留原精度。

## 固定调度验证结果

旧设置的 9 个配对实验全部逐数组复现当前全负载实验，新增诊断没有改变原有结果。以下比较的是**正文时隙级平均近似**与**实际方向性波束、显式 RB 映射**，不是把旧代码的最大元素增益误认为正文的平均增益。

| 每车负载 (Mbps) | seed 数 | 汇总 SINR 绝对误差中位数 (dB) | 汇总 SINR 绝对误差 P95 (dB) | 总潜在服务量相对偏差 |
|---:|---:|---:|---:|---:|
| 1 | 1 | 2.668 | 9.509 | −7.73% |
| 13 | 3 | 7.843 | 13.624 | −19.24% |
| 23 | 1 | 7.326 | 11.951 | −19.43% |
| 29 | 3 | 7.492 | 11.342 | −19.74% |
| 35 | 1 | 7.572 | 11.116 | −18.96% |

负号表示近似值低于显式方向性参考。这是总潜在服务量的偏差，不代表每条链路均低估服务率，也不构成干扰上界保证。例如 13、23 Mbps 的 RB 加权总干扰之比分别约 0.868、0.914，而大部分用户—时隙的汇总 SINR/总潜在服务量仍偏低。不同加权方式、少量强干扰样本及速率非线性使这些指标不能直接互相换算。

分开两项近似后，13 Mbps 的增益平均化与 RB 映射平均化分别对应 −8.43%、−11.80% 的潜在服务量偏差；29 Mbps 分别为 −15.76%、−4.73%。两个比值相乘才得到组合偏差，不能简单把两个百分比相加。这里前者比较 `average_expected / directional_expected`，后者比较 `directional_expected / directional_explicit`。

RB 重叠的全程总量与条件期望吻合：在 13、29 Mbps，合并三个 seed 后相对误差分别约为 +0.0057%、+0.0004%。但这个检查不能消除逐 RB 干扰变化经非线性速率公式引入的服务率差异。对固定信号强度和噪声，$\log_2(1+S/(N+I))$ 是关于 $I$ 的凸函数，一般不能把期望移入该函数；先平均干扰再计算服务率与先逐 RB 计算再求和不同。

仅把帧级平均增益改为时隙级平均增益，13、29 Mbps 的总潜在服务量变化都约为 −0.012%。在本组固定调度实验中，主要误差并非这一帧/时隙差异，而是增益定义与方向性、RB 映射的平均化。

## 闭环配对结果

下表均为 3 个 seed 的均值。三种设置均保持相同的预测器、决策算法及其输入来源，仅改变物理服务率的计算。每组都由相同轨迹、配对到达和衰落重新运行完整闭环。

| 每车负载 (Mbps) | 物理服务率计算 | 功率 (W) | $U$ (%) | P99 时延代理 (ms) |
|---:|---|---:|---:|---:|
| 13 | 旧代码 | 29.6650 | 0.2420 | 2.3212 |
| 13 | 正文平均近似 | 27.1843 | 0.2274 | 2.3057 |
| 13 | 实际方向性波束、显式 RB | 24.9769 | 0.1836 | 2.3168 |
| 29 | 旧代码 | 157.5207 | 0.8986 | 16.0527 |
| 29 | 正文平均近似 | 148.2759 | 0.1499 | 1.5431 |
| 29 | 实际方向性波束、显式 RB | 144.7598 | 0.0999 | 1.4556 |

相对正文平均近似，方向性物理评估使 13 Mbps 的功率降低 8.12%，$U$ 降低 0.04376 个百分点；29 Mbps 的功率降低 2.37%，$U$ 降低 0.05000 个百分点。相对旧代码，功率分别降低 15.80%、8.10%。这些对比的参照不同，不能混用。

方向性设置在 13 Mbps 的功率范围为 24.9760–24.9783 W，$U$ 范围为 0.18281%–0.18456%；29 Mbps 的对应范围为 144.7560–144.7646 W、0.09985%–0.09999%。其差异远小于各物理服务率设置之间的差异，说明观察到的变化不是单个 seed 偶然造成的；这仍仅是固定场景下的随机重复验证。

虽然功率和 $U$ 均降低，但不应把它表述为所有时延统计量均改善。例如 13 Mbps 的方向性 P99 为 2.3168 ms，略高于正文近似的 2.3057 ms。不同分位数与违反概率不能互相代替。

## 对 R2C1 的建议

1. 保留关于 DFT 码本均值和条件期望重叠的数学澄清，但不能再由此推断实际干扰或服务率偏差可忽略。本次数据支持的是审稿人给出的“定量比较”路径。
2. 后续可以继续将平均干扰作为低开销决策估计，同时把正式系统性能的物理评估改为实际方向性波束和显式 RB 映射；必须清楚区分算法内部的估计量与环境中的真实服务率。是否正式采用这一配置，需要用户确认后再统一修改。
3. 先统一正文干扰增益、训练标签、预测输出及各算法调用的定义，再用同一物理评估对 MEET-COBRA 与全部基线重跑。不能只替换 MEET-COBRA 曲线而让基线保留旧物理服务率。
4. 本次仅验证 MEET-COBRA，不能由其功率和 $U$ 改善推断原有基线排名仍保持，也不能声称在全部负载或其他地图上都已验证闭环鲁棒性。
5. 本轮不改动论文、回复信、既有 Fig.5–Fig.8 图片及原实验数据。后续回复可直接解释采用的近似、给出本次定量误差和统一物理评估结果，无须展开内部实现修改历史，但也不能将旧计算结果误称为正文 Frobenius 平均公式的结果。
