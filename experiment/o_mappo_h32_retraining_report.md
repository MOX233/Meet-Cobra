# O-MAPPO 分层32次：搜索一致的优化器与多负载重训

日期：2026-09-24。状态：训练及验证进行中，不能据此声称已收敛。

## 本轮问题

上一轮仅替换初始 BF 搜索、沿用旧 actor，并且优化器仍用全局最优窄波束增益估计候选 BS。本轮优化器使用当前帧信道经过同一分层32次搜索得到的增益，然后重新训练 actor。优化器不读取下一帧执行搜索后的结果。

保留原版特权 CSI 条件，即利用当前帧真实信道模拟候选 BS 的搜索结果，并未将“探测所有候选 BS 的额外开销”加入模型。实际获取、局部跟踪、HO 中断及逐 RB 方向性干扰的服务计算与前轮一致。

## 训练设计

- 三组随机初始化：11、22、33。不加载旧 actor 权重。
- 同一个 actor 覆盖全部18个负载点：1、3、…、35 Mbps。每轮每个负载各采集一个10 s片段，合并后进行PPO更新，不按负载分别选择模型。
- 训练轨迹时段：200–650 s；固定代理环境验证时段：700–710 s；独立精确仿真验证候选时段：710–740 s；最终测试：800–830 s。
- 仍采用原actor/critic架构、原状态组成和原 `qos_energy020_load1` 奖励权重。新增训练覆盖高负载，训练与评估均使用分层搜索增益、32次获取开销及10 ms HO中断。
- 搜索奖励项以固定256次为归一化基准，保持原奖励的计数单位，使32次获取确实比256次更便宜，也避免九次跟踪在新训练中被无意放大处罚。
- 训练与精确仿真均采用MILP目标BS优化器。PPO采样仍在原有帧级近似环境进行，不把代理环境的违反概率误当成最终系统仿真的违反概率。
- 每次PPO更新包含4个epoch，minibatch=256。学习率从3e-4逐步降至3e-5，保留非零下限；熵系数从0.01降至0.002。
- 初始计划最多160轮；未满足稳定性标准时，继续训练或诊断，不将达到轮数上限等同于收敛。

## 预先指定的稳定性检查

每10轮对全部18个负载进行固定验证。负载r的代价为

`C_r = U_r(%) + 0.02 * P_r(W)`。

以独立验证时段上“旧actor + 已修正优化器”的代价作逐负载归一化，综合分数为归一化代价均值和最坏值各占一半。该分数用于选择一个统一checkpoint，不在测试集上挑模型。

至少训练60轮，并在连续五次验证中同时满足：

1. 每个负载的代价相对极差均小于5%；
2. 综合分数相对极差小于2%；
3. 固定状态样本上的贪心动作变化率小于1%；
4. 固定状态样本上的平均动作概率变化小于0.005。

固定状态样本覆盖参照策略与随机初始策略的验证轨迹。上述检查仅构成经验上的近似收敛证据，不是全局最优或数学收敛证明；仍需精确仿真复核各负载的功率、违反概率和时延分位数。
