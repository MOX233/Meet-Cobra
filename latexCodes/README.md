# Manuscript directory

Current source: **`main_revision1_journal.tex`**.

`main.tex` is the original reviewed manuscript. `main_revision1.tex` is the
historical layout before conversion to the standard journal template; it is not
a second active manuscript. Both retain their relative paths for provenance.

`revision1/` contains the submitted materials and must not be overwritten.
Use a fresh ignored build directory for previews. Figure and bibliography paths
are relative to this directory; run LaTeX from here, not from the repository root.

See [the paper-file index](../docs/PAPER_FILES.md) for figure sources, historical
assets, advisor comments and the separate-backup policy.
